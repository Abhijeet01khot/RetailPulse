RetailPulse is a retail sales data pipeline built with Python and PySpark. It transforms synthetic order data into clean datasets and product-level sales summaries.

Three-layer data pipeline

Each layer has a distinct role in preparing data for analysis.

01 · Bronze

Stores the ingested order records as the raw processing layer.

500 records

Output: data/bronze/orders

02 · Silver

Removes duplicates, handles selected required fields, casts data types, and filters invalid values.

499 records

Output: data/silver/orders

03 · Gold

Aggregates total quantity and revenue by product for analysis.

8 product summaries

Output: data/gold/sales
